# Day 01 – Introduction to Java

## Overview
Day 1 focused on understanding the fundamentals of Java, its features, Java development environment, and the basic structure of a Java program.

## Topics Covered
1. Introduction to Java
2. Features of Java
3. Java Development Kit (JDK)
4. Java Runtime Environment (JRE)
5. Java Virtual Machine (JVM)
6. Java program structure
7. Compilation and execution of Java programs
8. Introduction to bytecode

## Programs Implemented

### 1. HelloWorld.java
- Created the first Java program.
- Displayed welcome messages using `System.out.println()`.

### 2. StudentDetails.java
- Displayed student information.
- Practiced printing multiple statements in a Java program.

## Technologies and Tools Used
- Programming Language: Java
- IDE: Visual Studio Code
- Terminal: VS Code Integrated Terminal
- Version Control: Git and GitHub

## Compilation and Execution

Compile the Java program:

```bash
javac Day-01/HelloWorld.java
```

Execute the program:

```bash
java -cp Day-01 HelloWorld
```

## Key Learnings
- Understood the basic concepts and features of Java.
- Learned the difference between JDK, JRE, and JVM.
- Understood how Java source code is compiled and executed.
- Practiced creating, compiling, and running Java programs.
- Learned the basic structure of a Java application.
