# Day 02 – JVM Architecture, Data Types and Operators

## Overview

Day 2 focused on understanding JVM architecture, Java primitive data types, variables, type casting and different types of operators.

## Topics Covered

### 1. JVM Architecture
- Java Virtual Machine (JVM)
- Class Loader
- Bytecode
- Runtime Memory Areas
- Execution Engine
- Java compilation and execution process

### 2. Variables
- Declaration of variables
- Initialization of variables
- Local variables
- Instance variables
- Static variables

### 3. Primitive Data Types
- byte
- short
- int
- long
- float
- double
- char
- boolean

### 4. Type Casting
- Widening Type Casting
- Narrowing Type Casting
- Implicit Conversion
- Explicit Conversion

### 5. Operators
- Arithmetic Operators
- Relational Operators
- Logical Operators
- Assignment Operators
- Unary Operators
