# Day 05 – Java Full Stack Training

## Topics Covered

1. **Constructors**
   - Default and parameterized constructors
   - Constructor overloading
   - Object initialization

2. **Encapsulation**
   - Data hiding using private variables
   - Accessing data through methods

3. **Access Modifiers**
   - Public
   - Private
   - Protected
   - Default

4. **POJO Class**
   - Plain Old Java Object
   - Variables, constructors, getters and setters

5. **Static and Final**
   - Static variables and methods
   - Final variables, methods and classes
   - Differences between static and final

6. **Type Conversion**
   - Integer.parseInt()

7. **Inheritance**
   - Parent and child classes
   - Method overriding
   - Runtime polymorphism
   - extends keyword

## Java Programs

### 1. Animal Sound – Animal.java
- Demonstrates inheritance and method overriding.
- Uses Animal as the parent class and Dog and Cat as child classes.

### 2. ATM Application – ATM.java
- Demonstrates encapsulation using a private balance variable.
- Includes balance checking, deposit and withdrawal operations.
- Uses methods, loops and switch statements.
