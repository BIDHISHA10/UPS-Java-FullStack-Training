# Day 09 – Core Java Assessment & Programming Practice

## Topics Covered
- Conditional statements and loops
- Break and continue
- One-dimensional and two-dimensional arrays
- Strings and string immutability
- Classes, objects, constructors and `this` keyword
- Encapsulation and inheritance
- Method overloading and runtime polymorphism
- User-defined exceptions

## Practical Programs

### 1. Anagram.java
Checks whether two strings are anagrams, ignoring spaces and letter case.

**Output:**
```text
The strings are anagrams.
```

### 2. Bank.java
Demonstrates a user-defined exception for insufficient bank balance during withdrawal.

**Output:**
```text
Insufficient balance!
Available balance: 5000
```

### 3. Bubble.java
Sorts an integer array in ascending order using Bubble Sort.

**Output:**
```text
4 8 12 21 35 67
```

### 4. Dupli.java
Finds and displays duplicate elements in an array without using collections or sorting.

**Output:**
```text
Duplicate elements: 4 2
```

### 5. Rotate.java
Rotates an array to the right by K positions.

**Output:**
```text
5 6 7 1 2 3 4
```

### 6. StudentCode.java
Calculates student totals, averages and grades, and identifies the topper.

**Output:**
```text
Bidhisha - Total: 277, Average: 92.33, Grade: A
Rahul - Total: 240, Average: 80.00, Grade: B
Priya - Total: 210, Average: 70.00, Grade: C
Topper: Bidhisha
```

### 7. Shapes.java
Demonstrates inheritance and runtime polymorphism by calculating the areas of different shapes.

**Output:**
```text
Circle Area: 153.86
Rectangle Area: 20.0
Triangle Area: 24.0
```

### 8. nonRepeating.java
Finds the first non-repeating character in a string.

**Output:**
```text
First non-repeating character: w
```
