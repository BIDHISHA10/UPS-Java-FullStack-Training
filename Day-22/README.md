# Day 22 – Teacher Management System using Spring Boot

## Overview
Developed a Teacher Management System using Spring Boot, Spring Data JPA and MySQL. The application provides REST APIs to perform CRUD operations on teacher records.

## Topics Covered
- Spring Boot application setup
- REST API development
- Entity creation using JPA
- Repository using JpaRepository
- Service layer implementation
- Controller layer implementation
- MySQL database connection
- CRUD operations
- API testing using Postman

## Technologies Used
- Java 21
- Spring Boot
- Spring Web
- Spring Data JPA
- MySQL
- Maven
- Postman

## Project Structure
- controller
- entity
- repository
- service
- TeacherManagementApplication

## API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| POST | /teachers | Add a teacher |
| GET | /teachers | Get all teachers |
| GET | /teachers/{id} | Get teacher by ID |
| DELETE | /teachers/{id} | Delete a teacher |

## Outcome
Successfully developed a Teacher Management System with REST APIs and MySQL database integration.
